# Portfolio Website

A modern, cyberpunk-themed portfolio website featuring:

- 🎨 Hacker terminal aesthetic with glowing effects
- 🎯 Custom cursor tracking with neon trail
- 💫 Holographic avatar with orbital rings and particles
- 📱 Fully responsive design
- ⚡ Dynamic typing animations in terminal sections

## Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- GitHub Pages (hosting)

## Features

- **Hero Section**: System boot sequence with holographic avatar
- **About**: Professional bio with animated stats
- **Technologies**: Terminal-style skill showcase with live animations
- **Projects**: CI/CD pipeline, Portfolio website, MERN stack project
- **Contact**: Social links (GitHub, LinkedIn)
